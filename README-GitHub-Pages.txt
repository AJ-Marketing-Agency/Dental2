MOHAMMADZAI DENTAL CLINIC — GITHUB PAGES READY

This is a flattened, static version of the uploaded DentaCare template.

IMPORTANT:
- Every website file is in THIS ONE FOLDER.
- There are NO subfolders.
- index.html is the homepage.
- No build process is required.
- No appointment form/modal is included.
- Blog, doctor/team pages and their unused assets were removed.
- Date/time picker dependencies were removed.
- Google Maps API dependency was removed and replaced with a static clinic location panel.
- All local CSS, JavaScript, image and font paths were changed to root-level paths.

UPLOAD TO GITHUB:
1. Extract this ZIP.
2. Open the Mohammadzai-Dental-Clinic-GitHub-Pages-Final folder.
3. Upload ALL files inside that folder directly into the ROOT of your GitHub repository.
4. Ensure index.html is directly in the repository root.
5. GitHub -> Settings -> Pages -> Deploy from branch -> main -> / (root).

The site uses Google Fonts externally. Everything else required for the website is included locally.
